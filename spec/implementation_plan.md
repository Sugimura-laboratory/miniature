# 実装計画：README.md の拡充

## 目的
本プロジェクトは、神奈川工科大学 杉村研究室が開発した、IoT教育用教材「IoTミニチュアハウス (Miniature IoT Unit Set)」の紹介サイトおよび関連ドキュメントのリポジトリです。
現在の `README.md` は非常に簡素（タイトルとURLのみ）であるため、リポジトリにアクセスした開発者や教育関係者がプロジェクトの目的、構成、利用可能なドキュメントを容易に理解できるよう、内容を大幅に充実させます。

## 主な記述内容
1. **プロジェクト概要**
   - IoTミニチュアハウスとは何か（本物の家電と同じ通信をするハードウェアエミュレーター）
   - 杉村研究室と企業との共同開発である点
2. **IoT教育の実習における課題と本プロジェクトの解決アプローチ**
   - 課題1：大型機器・家屋の設置と保管の困難さ -> スーツケースサイズのミニチュア化で解決
   - 課題2：個別IPアドレス割り振りの難しさ -> Wi-Fiルーター内蔵のリアルなネットワーク構成で解決
   - 課題3：持ち運びの困難さ -> 可搬性の高いパッケージング
3. **搭載・提供されているミニチュア家電ユニット**
   - スマートメーター
   - 鍵付き玄関扉
   - 壁照明 / フロア照明
   - 床暖房
   - テレビ
   - エアコン
   - 電動窓
4. **仕様書・ドキュメントへのリンク**
   - 各種ECHONET Lite仕様書（PDF）への相対リンク
   - 開発ボードインストールマニュアル（PDF）への相対リンク
   - 追加パーツ（PDF）への相対リンク
5. **関連リポジトリと外部リンク**
   - ファームウェアリポジトリ (LTS版 / α版) へのリンク
   - お問い合わせ（Notion）へのリンク
   - 杉村研究室・エコーネットコンソーシアム関連リンク
